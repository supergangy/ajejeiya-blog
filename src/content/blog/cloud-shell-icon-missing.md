## 증상: 안내에 나온 아이콘이 안 보여요

구글 클라우드 설정 스크립트를 Cloud Shell에 붙여넣으라는 안내를 따르려는데, 정작 <strong>"오른쪽 위 >_ 아이콘"</strong>이 보이지 않았습니다. 콘솔 위쪽을 아무리 둘러봐도 찾을 수가 없었어요.

Cloud Shell은 브라우저 안에서 바로 쓰는 리눅스 터미널입니다. 구글이 무료로 제공하고 `gcloud` 명령이 미리 설치돼 있어서, 내 컴퓨터에 아무것도 설치하지 않고 설정 작업을 할 수 있어요. 사용 한도 같은 세부 조건은 바뀔 수 있으니 공식 문서에서 확인하세요.

## 원인: 보통은 화면 폭 문제

Cloud Shell 아이콘은 보통 콘솔 위쪽 바의 오른쪽, 알림·도움말 아이콘 근처에 있는 `>_` 모양입니다. 마우스를 올리면 보통 'Cloud Shell 활성화'라고 나옵니다(2026년 10월 기준이며, 콘솔 화면 구성은 바뀔 수 있습니다).

그런데 브라우저 창이 좁으면 위쪽 바의 아이콘 일부가 <strong>⋮(더보기)</strong> 메뉴 안으로 들어가서 안 보일 수 있습니다. 먼저 이것부터 확인해 보세요.

| 시도 | 방법 |
|---|---|
| 창 넓히기 | 브라우저 창을 최대화 |
| 더보기 메뉴 확인 | 위쪽 바 오른쪽 끝의 ⋮ 클릭 |
| 확대 비율 낮추기 | `Ctrl` + `-`를 눌러 화면 축소 |

## 해결: 주소로 바로 열기 (가장 확실한 방법)

아이콘을 찾는 대신 저는 아래 주소로 바로 열었습니다. 전체 화면 Cloud Shell 터미널이 뜹니다.

```text
https://shell.cloud.google.com/?show=terminal
```

처음 쓰는 경우 약관 동의나 <strong>'Cloud Shell 승인(Authorize)'</strong> 창이 뜰 수 있는데, 승인하면 됩니다.

### 프로젝트가 선택돼 있는지 확인하기

이렇게 주소로 열면 <strong>프로젝트가 선택되지 않은 상태</strong>일 수 있습니다. 저도 이 상태를 겪었고, 그래서 설정 스크립트를 프로젝트 목록을 보여 준 뒤 번호로 고르게 바꿨어요. 직접 확인하고 설정하려면 아래 명령을 쓰면 됩니다.

```bash
# 현재 선택된 프로젝트 확인 (비어 있으면 미선택)
gcloud config get-value project

# 내 프로젝트 목록 보기
gcloud projects list

# 사용할 프로젝트 지정
gcloud config set project 프로젝트ID
```

### 붙여넣기와 복사

| 동작 | 방법 |
|---|---|
| 붙여넣기 | `Ctrl+V` 또는 마우스 오른쪽 → 붙여넣기 |
| 복사 | 드래그하면 복사되거나 `Ctrl+C` |

브라우저가 클립보드 접근을 허용할지 물으면 허용하세요.

## 여러 줄 스크립트를 붙여넣을 때 주의할 점

실제로 겪은 함정이 두 가지 있습니다.

1. 스크립트 중간에 `exit`가 있으면, 오류가 났을 때 <strong>Cloud Shell 창 자체가 닫혀 버립니다.</strong>
2. `read`로 입력을 받는 스크립트를 그냥 붙여넣으면, 뒤따르는 줄이 입력값으로 먹혀 버립니다.

그래서 스크립트 전체를 함수로 감싸고, `exit` 대신 `return`을 썼습니다. 이렇게 하면 함수 정의가 먼저 다 들어간 뒤 마지막 줄에서 실행되므로 `read`가 제대로 입력을 기다리고, 오류가 나도 창이 닫히지 않아요.

```bash
setup() {
  read -p "번호를 입력하세요: " num
  if [ -z "$num" ]; then
    echo "입력이 없어 중단합니다."
    return 1
  fi
  echo "선택한 번호: $num"
}; setup
```

> 남이 만든 스크립트를 붙여넣을 때는 `exit`가 들어 있는지 한 번 훑어보세요. 창이 닫혀 버리면 화면에 나왔던 오류 메시지를 확인하기 어려워집니다.

## 정리

- 아이콘이 안 보이면 먼저 창을 넓히거나 ⋮ 메뉴를 확인합니다.
- 가장 확실한 건 `https://shell.cloud.google.com/?show=terminal` 주소로 바로 여는 것입니다.
- 주소로 열었다면 `gcloud config get-value project`로 프로젝트부터 확인하세요.
- 여러 줄 스크립트는 함수로 감싸고 `exit` 대신 `return`을 쓰면 안전합니다.
