스캔한 문제집 PDF를 글자 검색이 되게 바꾸려고 구글 Cloud Vision OCR을 쓰기 시작했을 때, 가장 신경 쓰인 건 **요금**이었습니다. 유료 클라우드 서비스라 "모르는 사이에 돈이 나가면 어떡하지?" 하는 걱정이 들 수밖에 없죠. (이 작업은 나중에 [PDF OCR 프로그램](/blog/pdf-ocr-program/)으로 만들어 공개했습니다.)

결론부터 말하면, 424쪽짜리 문제집을 여러 번 OCR하면서 한 달에 약 1,700장을 처리했는데 **실제로 낸 돈은 0원**이었습니다. 이 글에서는 무료 구간과 크레딧이 어떻게 적용되는지, 제 사용량이 어떻게 계산됐는지, 요금을 아끼려고 했던 방법을 정리합니다.

> 요금과 무료 체험 정책은 바뀔 수 있습니다. 이 글은 **2026년 10월 기준**이고, 쓰기 전에 [구글 Cloud Vision 요금 안내](https://cloud.google.com/vision/pricing)를 꼭 확인해 주세요.

## Cloud Vision OCR 요금 구조

OCR에 쓰는 기능은 보통 두 가지입니다.

- **TEXT_DETECTION**: 사진 속 간판, 짧은 글자 인식용
- **DOCUMENT_TEXT_DETECTION**: 책, 문서처럼 글자가 빽빽한 이미지용

요금은 "단위(unit)"로 매깁니다. 이미지 1장이 1단위, PDF는 **페이지 1장이 1단위**예요.

| 구분 | 요금 (2026년 10월 기준) |
|---|---|
| 매달 처음 1,000단위 | **무료** (기능별로 따로) |
| 1,000단위 초과분 | 1,000단위당 약 1.5달러 |
| 아주 많이 쓰는 구간 | 단가가 더 낮아짐 |

여기서 "기능별로 따로"라는 말은, TEXT_DETECTION 1,000단위와 DOCUMENT_TEXT_DETECTION 1,000단위가 각각 무료라는 뜻입니다. 다만 한 가지 기능만 쓴다면 그냥 **매달 1,000장 무료**라고 생각하면 됩니다.

## 구글 클라우드 무료 체험 300달러 크레딧

구글 클라우드에 처음 가입하면 무료 체험으로 **300달러 크레딧**을 줍니다.

| 항목 | 내용 |
|---|---|
| 금액 | 300달러 |
| 유효 기간 | 90일 |
| 적용 방식 | 사용 요금이 크레딧에서 먼저 차감 |
| 크레딧이 끝나면 | 직접 유료 계정으로 전환하지 않았다면 자동으로 카드 결제되지 않음 |

카드를 등록하긴 하지만, 무료 체험 기간에는 내가 직접 **유료 계정으로 전환**하지 않는 한 크레딧을 다 써도 카드로 돈이 빠져나가지 않습니다. 이 부분도 정책이 바뀔 수 있으니 가입할 때 안내 문구를 한 번 읽어 보세요.

정리하면 요금이 빠지는 순서는 이렇습니다.

```text
1. 매달 무료 1,000단위 먼저 사용
2. 넘는 만큼 요금 발생
3. 그 요금은 300달러 크레딧에서 차감
4. 크레딧이 남아 있으면 실제 결제 금액은 0원
```

## 실제 사례: 424쪽 문제집, 한 달에 약 1,700장

제가 OCR한 건 424쪽짜리 문제집 PDF였습니다. 한 번만 돌렸으면 424장으로 끝났을 텐데, 시행착오가 있어서 사용량이 늘었어요.

1. **처음에는 인터넷에 나온 방법대로** PDF를 버킷(Cloud Storage)에 올리고, PDF 파일을 통째로 비동기 OCR(files API)에 보냈습니다. 이걸 **세 번** 했습니다.
2. 그런데 결과에서 ①②나 ㉠㉡ 같은 기호가 자주 깨졌습니다. 그래서 방식을 바꿔 **페이지를 300dpi 이미지로 만든 뒤 다시 424장**을 보냈어요.
3. 중간중간 **테스트로 몇 장**씩 더 보냈습니다.

그래서 그 달 사용량은 **약 1,700장**이었습니다. 계산해 보면 이렇습니다.

| 항목 | 장 수 / 금액 |
|---|---|
| 그 달 총 사용량 | 약 1,700장 |
| 무료 구간 | \- 1,000장 |
| 유료 사용량 | 약 700장 |
| 요금 | 700 × 1.5 ÷ 1,000 ≈ **약 1달러** |
| 300달러 크레딧에서 차감 후 실제 결제 | **0원** |

시행착오를 꽤 했는데도 요금은 1달러 정도였고, 그마저도 크레딧에서 빠져서 실제로 낸 돈은 없었습니다. 반대로 말하면, **크레딧이 없었거나 다 쓴 상태였다면 1달러 정도는 나왔을 것**이라는 뜻이기도 해요.

## 버킷 저장 비용은?

처음 방식처럼 PDF를 버킷에 올리면 저장 비용도 따로 붙습니다. 하지만 몇백 MB 수준이라면 걱정할 정도는 아니에요. Standard 저장소는 GB당 한 달에 몇 센트 수준이라, 몇백 MB면 **한 달 1센트도 안 됩니다**.

그래도 다 쓴 버킷은 지우는 걸 권합니다. 쓰지 않는 리소스를 남겨 두면 나중에 무엇이 요금을 만드는지 헷갈리기 쉽거든요. 다른 클라우드도 마찬가지예요. 안 쓰는 AWS 리소스 정리는 [Route 53 호스팅 영역 정리하기](/blog/aws-route53-hosted-zone-cleanup/)에 정리했습니다.

참고로 페이지를 이미지로 바꿔 보내는 방식은 이미지를 바로 API에 보내기 때문에 <strong>버킷이 아예 필요 없습니다.</strong> 저장 비용도, 버킷 설정도 없어지는 셈이에요.

## Vision API 사용량·청구액 확인하는 방법

| 확인할 것 | 위치 |
|---|---|
| 청구 금액, 크레딧 차감 내역 | 콘솔 **결제 → 보고서** |
| Vision API 호출량 | 콘솔 **API 및 서비스 → Vision API → 측정항목** |

주의할 점은 **청구 반영이 하루 정도 늦을 수 있다**는 겁니다. 방금 OCR을 돌렸는데 결제 보고서에 0원으로 나온다고 안심하지 말고, 다음 날 다시 확인해 보세요. 몇 장을 보냈는지는 측정항목에서 따로 확인할 수 있습니다.

## Vision OCR 예상 요금 미리 계산하기

OCR을 시작하기 전에 이 계산만 해 보면 대략적인 요금을 알 수 있습니다.

```python
def estimate_cost(pages_this_month):
    paid_pages = max(0, pages_this_month - 1000)  # 매달 1,000장 무료
    return paid_pages * 1.5 / 1000                # 1,000장당 약 1.5달러

print(estimate_cost(600))   # 300쪽 책 2권 → 0.0 (무료)
print(estimate_cost(3000))  # 3,000쪽 → 2,000쪽 유료 → 약 3.0달러
```

| 이번 달 총 페이지 | 유료 페이지 | 예상 요금 |
|---|---|---|
| 600쪽 (300쪽 책 2권) | 0쪽 | 무료 |
| 1,700쪽 (제 사례) | 700쪽 | 약 1달러 |
| 3,000쪽 | 2,000쪽 | 약 3달러 |

중요한 건 <strong>"이번 달 총 페이지"</strong> 기준이라는 점입니다. 같은 달에 여러 권을 하면 합쳐서 1,000장이 무료예요. 대량 구간 할인은 이 계산에 넣지 않았으니, 아주 많이 쓰는 경우에는 실제 요금이 조금 더 낮을 수 있습니다.

## 요금을 줄이는 방법 (프로그램에 넣은 기능)

제 경우 요금이 늘어난 이유는 결국 **같은 페이지를 여러 번 보낸 것**이었습니다. 그래서 직접 만든 [PDF OCR 프로그램](/blog/pdf-ocr-program/)에는 이런 기능을 넣었어요.

- **처음에는 1\~5쪽만 시험**: 설정이 맞는지 몇 장으로 먼저 확인하고 전체를 돌립니다.
- **페이지별로 결과 저장**: 중간에 끊겨도 다시 시작하면 이미 끝난 페이지는 건너뛰어서, 같은 페이지에 요금이 두 번 나가지 않습니다.
- **이미 글자가 있는 페이지는 건너뛰기**: 텍스트가 들어 있는 페이지는 OCR할 필요가 없으니까요.
- **시작 전에 페이지 수와 예상 요금 표시**: 위 계산식으로 미리 보여 줍니다.

### 덤: 이미지 방식이 품질도 더 좋았어요

요금 얘기는 아니지만, 다시 돌린 보람은 있었습니다. 같은 책에서 PDF 통째 방식과 300dpi 이미지 방식을 비교해 보니 이렇게 차이가 났어요.

| 인식된 기호 | PDF 통째 방식 | 300dpi 이미지 방식 |
|---|---|---|
| ①\~⑤ | 2,075개 | 2,462개 |
| ㉠\~㉤ | 225개 | 364개 |

처음부터 이미지 방식으로 했다면 424장에 테스트 몇 장 정도라 무료 구간 안에서 끝났을 겁니다. 시행착오 비용이 약 1달러였던 셈이에요.

## 자주 묻는 질문

### 크레딧을 다 쓰면 카드로 자동 결제되나요?

무료 체험 기간에는 내가 직접 **유료 계정으로 전환**하지 않았다면 자동으로 카드 결제되지 않습니다. 정책은 바뀔 수 있으니 가입할 때 안내 문구를 확인해 주세요.

### PDF 한 개는 몇 단위인가요?

PDF는 파일 개수가 아니라 **페이지 1장이 1단위**입니다. 424쪽 PDF를 한 번 돌리면 424단위입니다.

### TEXT_DETECTION과 DOCUMENT_TEXT_DETECTION 무료 구간은 따로인가요?

네. 매달 무료 1,000단위는 **기능별로 따로** 적용됩니다. 한 가지 기능만 쓴다면 매달 1,000장 무료라고 생각하면 됩니다.

### 방금 쓴 요금이 왜 0원으로 나오나요?

청구 반영이 하루 정도 늦을 수 있습니다. 다음 날 결제 → 보고서를 다시 확인하고, 몇 장을 보냈는지는 Vision API 측정항목에서 바로 볼 수 있습니다.

## 정리 체크리스트

- [ ] 요금은 **매달 1,000장 무료**, 그 뒤 1,000장당 약 1.5달러 (2026년 10월 기준)
- [ ] PDF는 **페이지 1장 = 1단위**로 계산된다
- [ ] 신규 가입 <strong>300달러 크레딧(90일)</strong> 에서 요금이 먼저 차감된다
- [ ] 유료 계정으로 직접 전환하지 않으면 크레딧이 끝나도 자동 결제되지 않는다 (정책 확인 필수)
- [ ] 시작 전에 `max(0, 이번 달 총 페이지 - 1000) × 1.5 ÷ 1000`으로 예상 요금을 계산한다
- [ ] 처음에는 몇 쪽만 시험하고, 같은 페이지를 다시 보내지 않게 한다
- [ ] 다 쓴 버킷은 지운다
- [ ] 결제 → 보고서는 **하루 뒤에** 다시 확인한다

책 한두 권 정도라면 무료 구간 안에서 충분히 해결됩니다. 다만 무료라고 안심하고 같은 파일을 여러 번 돌리다 보면 저처럼 금방 1,000장을 넘기니, 시험은 꼭 몇 장으로 먼저 해 보세요. 구글 클라우드 인증 설정에서 막혔다면 [서비스 계정 키 대신 API 키를 쓰는 방법](/blog/gcp-api-key-instead-of-service-account-key/)도 함께 참고해 보세요.
