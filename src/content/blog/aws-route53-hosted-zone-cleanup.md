AWS Route 53 호스팅 영역은 도메인을 다른 곳에서 쓰더라도 남아 있는 한 영역당 월 0.5달러(2026년 10월 기준)가 청구됩니다. 네임서버가 Route 53을 가리키지 않는지 확인한 뒤 NS·SOA를 뺀 레코드를 지우고 영역을 삭제하면 됩니다.

## 이런 상황이라면 한 번 확인해 보세요

이 블로그 도메인은 가비아에서 샀는데, 예전에 사이트 인증서(HTTPS) 때문에 AWS Route 53에 연결해 본 적이 있습니다. 나중에 도메인 등록 정보(RDAP)를 보니 네임서버가 Route 53 주소 4개(`ns-136.awsdns-17.com` 등)로 그대로 남아 있었어요. 마지막 변경일은 2026-09-09였고, AWS 쪽에서 응답이 없어 도메인 조회가 `Server failed`로 실패했습니다.

가비아 네임서버로 되돌려서 해결했고, 그 과정은 [가비아 도메인을 GitHub Pages에 연결하기](/blog/gabia-github-pages-domain/)에 정리해 두었습니다.

문제는 그다음입니다. 네임서버를 옮기고 나면 Route 53은 잊어버리기 쉬운데, **AWS에 호스팅 영역이 남아 있다면** 도메인을 쓰지 않아도 요금이 계속 나갑니다.

> 솔직히 말하면, 제 계정에 호스팅 영역이 실제로 남아 있는지는 확인하지 못했습니다. 그래서 이 글은 "남아 있다면 이렇게 정리한다"는 기준으로 씁니다.

## Route 53 호스팅 영역 요금: 도메인을 옮겨도 따로 나간다

호스팅 영역은 Route 53 안에 만들어 두는 도메인별 DNS 레코드 묶음입니다. 도메인의 네임서버가 어디를 가리키든 상관없이, <strong>영역이 존재하는 한</strong> 매달 청구됩니다.

| 항목 | 요금 (2026년 10월 기준) |
|---|---|
| 호스팅 영역 | 1개당 월 0.50달러 (처음 25개 기준) |
| DNS 쿼리 | 사용량에 따라 별도 |
| 만든 지 12시간 안에 지운 영역 | 청구되지 않음 |

한 달 0.5달러면 작은 금액이지만, 잊고 있으면 1년 내내 나갑니다. 도메인은 다른 곳에서 사고 Route 53은 잠깐만 써 본 경우라면 AWS 콘솔을 열 일이 적어 놓치기 쉽습니다. 요금은 바뀔 수 있으니 [AWS 공식 요금 페이지](https://aws.amazon.com/route53/pricing/)에서 한 번 확인하세요.

## 해결 1: 지우기 전에 꼭 확인할 것

### 지금 네임서버가 어디를 가리키는지

무작정 지우면 안 됩니다. 도메인이 아직 Route 53을 쓰고 있다면 영역을 지우는 순간 사이트가 끊겨요. 윈도우 명령 프롬프트에서 확인합니다.

```bat
nslookup -type=NS 내도메인 8.8.8.8
```

브라우저 주소창에 RDAP 주소를 넣어도 등록된 네임서버를 볼 수 있습니다.

```text
https://rdap.org/domain/내도메인
```

| 결과 | 할 일 |
|---|---|
| 가비아 등 다른 업체 네임서버 | Route 53 영역을 지워도 사이트에는 영향 없음 |
| `awsdns`가 들어간 주소 | 먼저 네임서버를 옮기고, 반영된 뒤에 삭제 |

### 다른 서비스가 같은 영역을 쓰는지

메일 같은 다른 서비스가 그 영역의 레코드를 쓰고 있지 않은지도 확인하세요. 네임서버가 이미 다른 곳으로 옮겨졌다면 보통 문제없지만, 지우기 전에 레코드 목록을 한 번 훑어보는 게 안전합니다.

## 해결 2: Route 53 호스팅 영역 삭제 순서

1. AWS 콘솔에서 **Route 53 → 호스팅 영역**으로 들어갑니다.
2. 정리할 도메인의 영역을 선택합니다.
3. 기본으로 있는 **NS, SOA 레코드를 뺀 나머지 레코드**를 선택해 먼저 삭제합니다. NS·SOA는 영역을 지울 때 함께 사라집니다.
4. 레코드를 다 지운 뒤 **호스팅 영역 삭제**를 누릅니다.

메뉴 이름은 콘솔 언어 설정에 따라 다르게 보일 수 있습니다(2026년 10월 기준). AWS CLI를 쓴다면 아래 명령으로 남아 있는 영역 목록을 먼저 볼 수 있어요.

```bash
aws route53 list-hosted-zones
```

삭제한 뒤에는 앞에서 썼던 `nslookup` 명령으로 사이트 도메인이 여전히 정상으로 조회되는지 한 번 더 확인해 두면 마음이 편합니다.

## Route 53 요금이 나가고 있는지 확인하는 법

- <strong>결제 콘솔(Billing)</strong>의 청구서에서 Route 53 항목이 있는지 봅니다.
- <strong>비용 탐색기(Cost Explorer)</strong>에서 서비스별로 나눠 보면 더 쉽게 찾을 수 있습니다.
- **AWS Budgets**로 예산 알림을 걸어 두면, 잊고 있던 요금을 빨리 알아챌 수 있습니다.

결제 화면의 메뉴 이름과 위치도 바뀔 수 있습니다(2026년 10월 기준).

## 자주 묻는 질문

### 호스팅 영역을 지우면 사이트가 끊기나요?

네임서버가 가비아 등 다른 업체를 가리키고 있다면 영향이 없습니다. 네임서버 주소에 `awsdns`가 들어 있다면 아직 Route 53을 쓰고 있는 것이니, 먼저 네임서버를 옮기고 반영된 뒤에 삭제하세요.

### 만들자마자 지우면 요금이 나오나요?

만든 지 12시간 안에 지운 호스팅 영역은 청구되지 않습니다(2026년 10월 기준).

## 정리

- [ ] 네임서버가 Route 53을 가리키지 않는지 먼저 확인
- [ ] 다른 서비스가 그 영역을 쓰지 않는지 확인
- [ ] NS·SOA를 뺀 레코드 삭제 후 호스팅 영역 삭제
- [ ] 결제 콘솔에서 Route 53 요금 확인, 예산 알림 설정

테스트로 만든 클라우드 리소스는 끝나면 바로 정리 목록을 만들어 두는 게 좋습니다. 도메인 등록업체의 네임서버도 원래대로 돌려놓는 것까지가 정리예요. 클라우드 요금을 직접 확인해 본 다른 사례는 [구글 Cloud Vision OCR 요금 정리](/blog/google-vision-ocr-pricing/)에도 있습니다.
